## 📦 Installation

### 1. Clone & Install

```bash
git clone https://github.com/pratikshakalbhor/MyPortfolio.git
cd MyPortfolio
npm install
```

### 2. Configure EmailJS Credentials

Add your EmailJS credentials by creating a `.env` file in the root directory:

```env
VITE_EMAILJS_SERVICE_ID="your_service_id"
VITE_EMAILJS_TEMPLATE_ID="your_template_id"
VITE_EMAILJS_PUBLIC_KEY="your_public_key"
```

> **Note:** If these env variables are left empty, the contact form automatically executes a simulation fallback with simulated server latency and full confetti trigger to keep the page fully functional.

### 3. Launch Development Server

```bash
npm run dev
```

The application will launch on `http://localhost:5173` with hot-module reloading active.

### 4. Build for Production

```bash
npm run build
```

This generates optimized static assets inside the `dist/` directory, ready to deploy to **Vercel**, **Netlify**, or **GitHub Pages**.
